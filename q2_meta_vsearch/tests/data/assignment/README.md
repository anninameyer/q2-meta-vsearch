# Assignment fixtures

These are software-validation fixtures, not biological observations. The
`evidence*` directories were generated by the unchanged `align_closed_reference`
implementation with real VSEARCH 2.22.1 and validated at maximum level. Their
`search.json` files preserve the generating command, input fingerprints, version,
and search options. No VSEARCH execution is needed for assignment tests.

The query/reference FASTA files derive from the existing M2 alignment fixtures.
Three references have identical 200-base sequences. Their artificial annotations
can represent one species, two species with unequal reference multiplicity,
three species, differing genera/domains, missing annotations, or nonstandard
species labels. The lower-identity fourth reference has deliberately discordant
taxonomy to test sequence-evidence dominance.

Additional evidence tests reference order permutations, removing a duplicate
reference, numeric-only identifiers, differently covered exact ties, a unique
hit, an unmatched query, and the M2 rounded-identity collision.

`lineages.json` specifies parser expectations. The no-hit BLAST6 fixture tests
semantic input rejection. Duplicate taxonomy IDs intentionally form invalid
input for the taxonomy reader.
